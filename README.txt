PORTFOLIO SAKHRI ABDELKHALAK

Fichiers :
- index.html : contenu du site
- style.css : design responsive
- script.js : menu mobile et formulaire email

AVANT PUBLICATION :
1. Remplace VOTRE-EMAIL@example.com dans index.html et script.js.
2. Remplace le numéro de téléphone provisoire dans index.html.
3. Ajoute ton CV PDF dans ce dossier sous le nom cv-sakhri.pdf.
4. Vérifie les niveaux de compétences et ajuste les barres.
5. Les cartes WordPress et Application web sont des emplacements provisoires : remplace-les par tes vrais projets quand ils seront publiés.

PUBLICATION GITHUB PAGES :
1. Crée un dépôt public nommé portfolio sur GitHub.
2. Envoie index.html, style.css, script.js et les fichiers nécessaires à la racine du dépôt.
3. Dans Settings > Pages, choisis Deploy from a branch, sélectionne main et / (root), puis Save.
4. Attends la publication. Le lien devrait être https://sakhriabdelkhalak-dev.github.io/portfolio/ si le nom du dépôt est portfolio.
